模板名称：基础响应式网站
模板版本：basic-v1
适用类型：multi_file
技术栈：HTML、原生 CSS、原生 JavaScript，无第三方依赖。

用途：
提供导航栏、内容卡片、页脚和基础交互的参考结构。
页面标题、文案、配色和业务交互应根据用户需求调整。
这是一份参考代码，不代表对应文件已经存在于当前应用目录。

script.js
```javascript
const actionButton = document.getElementById('action-button');
const actionMessage = document.getElementById('action-message');

if (actionButton && actionMessage) {
  actionButton.addEventListener('click', () => {
    actionMessage.textContent = '欢迎探索网站，下面是主要功能介绍。';
    document.getElementById('features')?.scrollIntoView({
      behavior: 'smooth'
    });
  });
}
```
